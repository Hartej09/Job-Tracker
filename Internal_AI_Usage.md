# Internal AI Usage

The internal AI project is aimed at supporting the energy assessments performed by professors and students by reducing the need for repetitive data entry and help organize and retrieve information.

## How AI can help for performing energy assessments:
- **Utility Bills:** The current prototype organizes the bills based on the billing period, usage, and charges from different utility groups such as Electricity, Water, and Natural Gas. A front-end provides file selection and drag and drop uploads of bills to have them extracted using API calls and store the extracted information in a database/ excel with validation summary.
- **Equipment Nameplates (Motorplates):** The current prototype is an image-to-text extractor that extracts model numbers, equipment ratings and other miscellaneus information with validation results from uploaded pictures. A capture and review interface is used to have the users verify and approve the extracted information. Integration with a mobile camera to perform live capture and extraction model is being planned to be developed along with API integration to gather additional information based on model numbers and store the extracted data in a database.
- **Reports:** A chat-based interface helps students search assessment reports, utility bills, and equipment nameplates uploaded into a connected database for references and checking historical recommendations.

These tools can help reduce the time spent (approximately xxxx hours/ minutes) by students on analyzing historical records of assessments and recommendations, basic data retrieval from the collected data during a site visit such as utility bills, and equipment nameplates, gathering additional information based on the retrieved data and performing basic preliminary calculations such as unit or power conversions. This gives them more time to analyze the findings and develop the recommendations.
