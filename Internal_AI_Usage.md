# Internal AI Usage

A lot of time is invested in energy assessments to decode and organise the data collected from the manufactures in the form of Utility Bills and Motorplates. To tackle this issue, implementation of AI as a tool to assist has been thought for. 

## Ways AI can help for performing energy assessments:
1. The utility bills can be fed into an AI and have it make an API call to read the data and gather additional information relating to the specific energy plans/ programs mentioned on the bills and store the information in a database which would take only minutes and can be run from anywhere
2. The motorplate scrapper can be used to identify and read all the data from a motorplate image and API calls can be made to gather additional information about an equipment based on the model number in just seconds to minutes and can be stored in a database for a future reference. Integration with a mobile camera can make this a live input into the system bypassing the need for separate storage and uploads in a cloud.
3. This could save the students and professors xxxx hours that is put into organising the information and help them to look up any information in real time by utilising the database and interactive front-end.
